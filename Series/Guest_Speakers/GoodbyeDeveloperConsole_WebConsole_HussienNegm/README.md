## 👋 أهلاً بيك

من Winter '27، الـ Developer Console بقى مقفول by default، والـ Web Console بقى هو الـ IDE اللي جوه الـ org بتاعك على طول. لو فتحته وسألت نفسك فين Execute Anonymous، فين الـ logs، أو إزاي تشغّل الـ tests، السيشن دي ليك.

## 📋 هنتكلم عن إيه

- تشغيل Anonymous Apex، قراءة الـ debug logs وضبط الـ trace flags
- إنشاء Apex classes وعمل tests ليها
- كتابة queries بالـ SOQL Builder وتصفّح الـ metadata بالـ Org Browser
- الحاجات اللي بتوقّع الناس في أول أسبوع
- Agentforce Vibes IDE قصاد Web Console: كل واحد بيعمل إيه، وإمتى تستخدم أنهي واحد
- بناء Lightning Web Component ونشره على الـ Home page من الموبايل
